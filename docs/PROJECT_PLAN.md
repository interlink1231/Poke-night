# PROJECT POKÉMON WORLD — 프로젝트 기획

## 게임 개요

Poke-night는 여러 지방을 하나의 긴 여행으로 연결하는 2D 픽셀 기반 싱글플레이 웹 RPG를 목표로 합니다. 자유로운 월드 탐험을 중심으로 포획·육성·턴제 전투와 로그라이크식 연속 도전 콘텐츠를 결합합니다.

## 핵심 결정사항

| 항목 | 결정 |
| --- | --- |
| 프로젝트명 | Poke-night |
| 장르 | 월드 탐험 RPG + 로그라이크 전투 |
| 플랫폼 | 웹 |
| 플레이 방식 | 싱글플레이 |
| 탐험 | 오픈월드형 자유 탐험 |
| 전투 | 본가 스타일 턴제 + 로그라이크 연속 전투 |
| 월드 구성 | 모든 주요 지방을 하나의 여행으로 연결 |
| 그래픽 | 2D 픽셀 아트 |
| 운영 방향 | 무료·비영리 지향 |

## 월드 구성

- 관동, 성도, 호연, 신오, 하나, 칼로스, 알로라, 가라르, 팔데아
- 히스이는 신오의 과거 시대를 다루는 별도 시간대 콘텐츠로 기획합니다.

지방은 단계적으로 개방하되 최종 목표는 모든 지방을 방문하고 다시 이동할 수 있는 통합 월드입니다. 첫 개발 단계의 테스트 지역과 최종 콘텐츠 목표를 혼동하지 않습니다.

## 탐험 시스템

- 키보드 방향키 및 WASD 이동, 모바일 터치 조작
- 타일 기반 맵과 충돌 처리
- 건물 출입 및 지역 간 이동
- NPC 상호작용과 대화
- 아이템 발견 및 퀘스트 진행
- 지역별 미니맵과 월드맵

## 포켓몬 시스템

종족 데이터와 플레이어 소유 개체 데이터를 분리합니다.

종족 데이터에는 도감 번호, 타입, 기본 능력치, 특성, 습득 기술, 진화 관계, 폼과 서식지를 포함합니다. 개체 데이터에는 고유 식별자, 레벨, 경험치, 성격, 특성, 개체값, 노력치, 현재 HP, 상태, 보유 기술과 포획 정보를 포함합니다.

파티는 최대 6마리이며 나머지는 박스에 보관합니다. 교환이 필요한 진화 방식은 싱글플레이에 맞는 대체 조건을 별도로 설계합니다.

## 전투 시스템

기본 전투는 턴제 방식이며 기술 선택, 포켓몬 교체, 아이템 사용, 도주를 지원합니다. 포켓몬은 최대 4개의 기술을 보유합니다.

로그라이크 도전 구간은 여러 전투와 이벤트를 연속으로 진행합니다. 전투 후 회복·아이템·기술 관련 보상을 선택하고 다음 구간으로 이동하며, 도전 종료 시 임시 효과를 초기화합니다.

## 성장 및 수집

- 플레이어 여행 기록
- 지방별 진행률과 배지
- 발견·포획 도감
- 업적 및 퀘스트
- 게임 내 재화
- 파티와 박스 관리

유료 결제, 현금화, 확률형 유료 상품은 프로젝트 방향에서 제외합니다.

## 개발 단계

1. 기반 구축: Next.js, TypeScript, 기본 화면, Phaser 연결
2. 월드 엔진: 타일맵, 이동, 충돌, NPC, 장소 전환
3. 포켓몬 핵심 기능: 데이터, 포획, 파티, 박스, 진화
4. 전투: 턴제 전투, 타입 상성, 트레이너, 연속 도전
5. 월드 콘텐츠: 첫 지방의 플레이 구간, 스토리, 퀘스트, 지방 이동
6. 운영 및 확장: 계정, 저장, 관리자, 보안, 나머지 지방과 엔드게임

## 권리 및 리소스 원칙

무료·비영리 프로젝트라도 저작권과 상표권 문제가 자동으로 해소되지는 않습니다. 데이터 API가 제공된다는 사실만으로 이미지·스프라이트·음악·캐릭터 자료의 재배포 권리가 생기는 것도 아닙니다. 공개 배포 전 권리자 정책과 각 리소스의 라이선스를 확인합니다. 권리가 확인되지 않은 공식 이미지·음악·효과음은 저장소에 추가하지 않습니다.
