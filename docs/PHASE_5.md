# Phase 5 — 파티 및 기술 관리

## 구현 범위
- P 키로 파티 관리 패널 열기/닫기
- 파티 목록에서 생존한 포켓몬을 선택해 선두 포켓몬으로 교체
- 종별 복수 기술 데이터 추가
- 전투에서 최대 4개 기술을 선택해 사용
- H 키로 파티 전체 회복 (테스트 편의 기능)

## 조작
- P: 파티 패널
- 파티 항목 선택: 선두 포켓몬 교체
- 전투 1~4: 기술 선택
- 전투 5: 포획
- 전투 6: 도주
- H: 파티 전체 회복

## 제한
- 기술 습득·삭제 UI, PP, 상태 이상, 저장 기능은 미구현
- 회복 키는 개발 테스트용이며 정식 게임에서는 회복 장소/아이템으로 대체
- 현재 데이터는 창작 테스트 생명체
- 빌드 및 브라우저 검증은 별도 수행 필요
