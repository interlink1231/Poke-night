# Phase 4 — 성장 시스템 프로토타입

## 구현 범위
- 전투 승리 시 경험치 지급
- 경험치 누적에 따른 레벨업 (최대 Lv.100)
- 레벨업 시 최대 HP 증가 및 현재 HP 일부 회복
- 풀·불꽃·물 3개 속성의 기본 상성 배율
- 종별 기본 기술 데이터 분리
- P 키로 파티 정보 및 발견 도감 수 확인
- 포획한 종은 도감 발견 항목에 등록

## 현재 제한
- 파티 교체, 개별 기술 선택, 기술 4개 제한은 다음 단계
- 진화, 상태 이상, 저장/계정 연동 미구현
- 속성 상성은 현재 3개 창작 테스트 속성만 지원
- 브라우저 및 빌드 검증은 별도 수행 필요
