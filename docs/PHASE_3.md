# Phase 3 — 야생 조우 및 전투 프로토타입

## 구현 범위

- 외곽 길의 키 큰 풀숲 타일(`g`)에서 야생 생명체 조우 판정
- 지역별 조우 확률과 출현 목록을 월드 맵 데이터에서 관리
- 생명체 종족 데이터와 전투 개체 상태 분리
- 턴제 공격, 상대 반격, 포획, 도주
- 포획 도구 수량과 최대 6마리 파티 제한
- PC 키보드와 Phaser 화면 내 전투 버튼 입력 지원

## 데이터 파일

- `data/creatures.json`: 테스트용 창작 생명체의 이름, 속성, 기본 능력치
- `data/worldMaps.json`: 지역 타일, 출현 확률, 출현 목록, 레벨 범위

## 현재 테스트 생명체

| ID | 이름 | 속성 |
| --- | --- | --- |
| mossling | 모스링 | 풀 |
| emberkit | 엠버킷 | 불꽃 |
| aquabud | 아쿠버드 | 물 |

이 데이터는 전투 흐름 검증을 위한 창작 임시 데이터이며 공식 캐릭터나 공식 게임 데이터를 포함하지 않습니다.

## 조작

- 이동: WASD 또는 방향키, 모바일 화면 방향 버튼
- 공격: 키보드 1 또는 전투 화면의 공격 버튼
- 포획: 키보드 2 또는 전투 화면의 포획 버튼
- 도주: 키보드 3 또는 전투 화면의 도주 버튼

## 미구현 및 제한사항

- 전투 및 파티 데이터는 브라우저 메모리에만 존재하며 새로고침하면 초기화됩니다.
- 포획 확률과 피해량은 밸런스 검증용 임시 공식입니다.
- 타입 상성, 기술 선택, 상태 이상, 교체, 경험치·레벨업, 진화는 미구현입니다.
- 서버 검증, 계정 연동, 저장 API는 미구현입니다.
- 권리가 확인되지 않은 공식 리소스는 사용하지 않으며 테스트 생명체는 코드 도형과 창작 데이터로 구성합니다.
