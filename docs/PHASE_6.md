# Phase 6 — 브라우저 저장 및 이어하기

## 목표

브라우저를 새로고침하거나 다시 방문해도 기존 모험을 이어갈 수 있도록 클라이언트 저장 기능을 추가합니다.

## 저장 방식

- 브라우저 localStorage 사용
- 저장 키: `pokenight-save-v1`
- 데이터 버전: `1`
- 브라우저 전용 API는 Phaser가 클라이언트에서 시작된 뒤 접근

## 저장 항목

- 현재 지역 ID
- 플레이어의 월드 좌표
- 파티 구성, 레벨, HP, 경험치
- 도감 발견 목록
- 포획 도구 수량
- 마지막 저장 시각

## 저장 시점

- 플레이어 이동 중 주기 저장
- 지역 이동 직후
- 전투 종료 후
- 포획 및 경험치 반영 후
- 파티 교체 및 회복 후

## 화면 기능

- 저장 데이터 상태 표시
- 이어하기 버튼
- 새 게임 버튼
- 새 게임 시작 전 덮어쓰기 확인

## 데이터 보호

- 저장 버전 확인
- 지역 ID와 좌표 유효성 확인
- 파티 최대 6마리 제한
- 존재하지 않는 생명체 ID 제외
- 레벨, HP, 포획 도구 수량 범위 보정
- 저장 데이터 파싱 실패 시 게임 기본 상태로 시작

## 제한 사항

- 저장 데이터는 현재 브라우저에만 존재합니다.
- 브라우저 데이터 삭제, 시크릿 모드, 다른 기기에서는 이어하기가 불가능합니다.
- 계정 동기화와 서버 저장은 추후 백엔드 단계에서 구현합니다.
- 현재 저장 데이터는 테스트용 창작 생명체 데이터를 기준으로 합니다.

## 검증 항목

- 이동 후 새로고침 시 위치 복원
- 포획 후 새로고침 시 파티 복원
- 레벨업 후 새로고침 시 레벨 및 경험치 복원
- 지역 이동 후 새로고침 시 지역 복원
- 새 게임 확인 후 기본 상태 초기화
- 잘못된 저장 데이터에서 오류 없이 기본 게임 시작
