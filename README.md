# Poke-night

모든 포켓몬 지방을 하나의 긴 여정으로 탐험하는 2D 픽셀 기반 싱글플레이 웹 RPG 프로젝트입니다.

> 본 프로젝트는 비공식 팬 프로젝트를 구상하는 저장소입니다. 포켓몬 및 관련 명칭·캐릭터·게임 데이터·이미지 등 제3자의 권리는 각 권리자에게 있습니다. 비영리·무료 운영이 권리 문제를 자동으로 해결하지는 않습니다. 공개 배포 전 필요한 권리와 이용 조건을 확인해야 합니다.

## 프로젝트 방향

- 장르: 월드 탐험형 RPG + 로그라이크 연속 전투
- 플랫폼: 웹 브라우저
- 플레이: 싱글플레이
- 그래픽 방향: 2D 픽셀 아트
- 월드: 관동부터 팔데아까지 주요 지방을 연결하는 통합 여행, 히스이는 별도 시대 콘텐츠로 검토
- 전투: 본가 스타일 턴제 전투와 탐험 구간별 로그라이크 보상 구조의 결합
- 운영 목표: 무료·비영리 방향

## 기술 구성

- 프론트엔드: Next.js, React, TypeScript
- 게임 화면: Phaser
- 백엔드: Python FastAPI
- 데이터베이스: PostgreSQL
- 캐시 및 세션: Redis 도입 여부는 실제 요구량에 따라 결정

## 개발 원칙

1. 먼저 브라우저에서 실행되는 기본 화면과 게임 캔버스를 구축합니다.
2. 이동·충돌·맵 전환을 구현한 뒤 포켓몬 데이터와 전투 시스템을 연결합니다.
3. 게임의 핵심 판정과 저장 데이터는 서버에서 검증합니다.
4. 이미지·음악·효과음은 권리 확인이 끝난 자료 또는 직접 제작한 자료만 사용합니다.
5. 모든 지방을 최종 목표로 유지하되, 개발 단계별로 완성 범위를 명확히 나눕니다.

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 저장 시스템

- 저장 위치: 현재 브라우저의 localStorage
- 자동 저장: 이동 중 주기 저장 및 전투·파티·지역 변경 시 저장
- 저장 항목: 지역, 플레이어 위치, 파티, 도감 발견 정보, 포획 도구 수량
- 이어하기: 기존 브라우저 저장 데이터 불러오기
- 새 게임: 확인 후 현재 저장 데이터를 새 모험으로 덮어쓰기
- 제한: 브라우저 데이터 삭제 또는 다른 기기 사용 시 저장 데이터가 공유되지 않음
